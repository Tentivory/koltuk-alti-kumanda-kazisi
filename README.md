# Koltuk Altı Kumanda Kazısı

TentiAŞ Minder Arkeolojisi Dairesi’nin 09 Ekim 2026 tarihli ve tamamen gereksiz kamu hizmetidir.

Kumanda kaybolmadı. Kumanda **gömüldü**. Sen de her seferinde ayağınla aradın, bu bilimsel değil. Bu depo, koltuk minderi altını katman katman kazan, kırıntıyı eser, pili sanık ilan eden çalışan bir Türkçe arkeoloji dairesidir.

Patates yoktur. Minder konuşur, kumanda susar, televizyon zaten açık kalmıştır.

## Neden var

Çünkü bir ülke, kumandasını koltuğun altında ararken bile tutanak tutmalıdır. Tutmazsa kırıntılar kazanır.

## Kurulum

Python 3 yeter. Bağımlılık yok. Minder satın almana gerek yok, zaten üzerinde oturuyorsun.

```bash
python3 kazi.py
python3 kazi.py --derinlik 5 --koltuk berjer
python3 kazi.py --hedef pil
```

## Ne yapar

1. Koltuk tipini seçer (kanepe, berjer, kayınvalide koltuğu).
2. Katmanları kazar: toz, simit kırıntısı, 2014 ten kuruş, kayıp çorap teki, nihayet kumanda.
3. Pili sorgular. Pil bitmişse suç ortağı ilan edilir, bitmemişse “sadece utançtan susmuş” sayılır.
4. JSON tutanak basar. Çıktıyı duvara asabilirsin, komşu zaten bakmaz.

## Bilimsel yöntem

- Kazı fırçası: eski diş fırçası.
- Ölçü birimi: bir el yordamı.
- Kontrol grubu: öteki koltuk. O da boş çıkarsa suç televizyondadır.

## Lisans

Kumandayı bulursan senindir. Bulamazsan koltukundur. İkisi de aynı kişi olabilir.
